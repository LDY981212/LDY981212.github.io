가로 스크롤, 프로젝트 모달)은 커밋 `02f33ce`로 처리했다. 이 문서는 남은 4~6번을 다룬다.

## 제약

`next.config.ts`가 `output: "export"`라 완전 정적이다. 서버가 없으므로:

- 테마는 `<head>` 인라인 스크립트로 페인트 전에 `<html data-theme>`에 주입해야 FOUC가 없다.
- 모든 상태는 클라이언트 사이드. 테마 선택은 `localStorage`에 저장한다.
- 이미지 최적화가 꺼져 있으므로(`images.unoptimized`) 배경은 이미지 대신 CSS/SVG로 만든다.

## 1. 색 토큰

현재는 `bg-blue-300`, `bg-gray-100`, `bg-gray-200`이 컴포넌트에 하드코딩되어 있어 다크모드가
불가능하다. CSS 변수 기반 시맨틱 토큰으로 교체한다.

| 토큰 | 라이트 | 다크 | 용도 |
| --- | --- | --- | --- |
| `--paper` | `#F7F8FA` | `#0B1020` | 페이지 배경 |
| `--surface` | `#FFFFFF` | `#141C33` | 카드 |
| `--surface-2` | `#EEF2F9` | `#1B2542` | 한 단계 낮은 면 |
| `--ink` | `#0B1020` | `#E8EDF7` | 본문 |
| `--muted` | `#5B6478` | `#94A0B8` | 보조 텍스트 |
| `--accent` | `#2F6BFF` | `#5B8CFF` | 주 액센트 |
| `--accent-soft` | `#E7EEFF` | `#1E2C55` | 액센트 배경 |
| `--amber` | `#F59E0B` | `#FBBF24` | 형광펜 전용 |
| `--line` | `#E2E6EE` | `#232C47` | 구분선 |

다크 배경은 순수 검정이 아닌 잉크 네이비(`#0B1020`)를 쓴다. 순수 검정 + 단일 형광색은
지금 가장 흔한 기본값이라 피한다.

액센트를 파랑으로 유지하는 이유: 기존 히어로 강조어·CTA·링크가 이미 전부 파랑이라
브랜드 연속성이 있다. 채도만 올린다. 앰버는 히어로 형광펜 한 군데에만 쓴다.

테마 전환은 `<html data-theme="light|dark">`. 초기값은 `localStorage` → 없으면 OS 설정.

## 2. 타이포

Pretendard는 45~920 가변인데 현재 bold/black만 사용 중이다. 여기에 시스템 모노스페이스를
유틸리티 서체로 추가한다(폰트 파일 추가 다운로드 없음).

- 디스플레이: Pretendard 900, `letter-spacing: -0.03em`
- 본문: Pretendard 400/500
- 라벨·날짜·기술 스택: 모노. 프론트엔드 개발자의 표기 관습이라 의미가 있다.

섹션 제목 위 eyebrow에 번호(01/02/03)는 쓰지 않는다. PROFILES → SKILLS → PROJECTS → CAREER는
순서가 정보를 담은 시퀀스가 아니다. 대신 실제 정보를 넣는다.

```
PROFILES  ─  이도엽 · 한양대 생체공학
PROJECTS  ─  4건 · 2024–2025
```

## 3. 시그니처

히어로 문장이 스스로 완성되고, 강조어가 주기적으로 교체된다.

```
안녕하세요.
더 나은 [사용자 경험]을 고민하고,
끊임없이 [성장]하는
프론트엔드 개발자 [이도엽]입니다.
```

첫 번째 강조 자리의 단어가 순환한다: 사용자 경험 → 성능 → 접근성 → AI 활용 → 유지보수.
"끊임없이 성장하는"이라고 쓰는 대신 문장이 실제로 계속 변하게 만든다. 카피의 내용과 모션이
같은 말을 한다.

조사는 단어별로 분기한다(받침 유무에 따라 을/를).

배경은 키보드 스톡사진을 걷어내고 포인터를 천천히 따라오는 그라디언트 + 미세 격자로 바꾼다.
격자는 프론트엔드의 레이아웃 은유이고, 다크에서 앰버 글로우가 살아난다.

## 4. 모션 시스템

| # | 위치 | 동작 |
| --- | --- | --- |
| 1 | 히어로 | 로드 시퀀스: 배경 → 문장 라인별 마스크 리빌 → 형광펜 스윕 → CTA |
| 2 | 내비 | 상단 스크롤 진행바, 현재 섹션 활성 표시(IntersectionObserver) |
| 3 | 전 섹션 | 기존 stagger 리빌 + blur-in |
| 4 | 프로젝트 카드 | 포인터 추종 3D tilt + 스포트라이트 |
| 5 | 우하단 | 맨 위로 버튼(20% 스크롤 후 등장) |
| 6 | 전역 | `prefers-reduced-motion` 완전 존중 |

6번은 협상 불가다. CSS 전역 규칙과 framer-motion `useReducedMotion` 양쪽으로 처리한다.

## 5. 푸터 · 햄버거

- 푸터: 연락 CTA(이메일 복사) + GitHub/이메일 + 맨 위로 + copyright.
  현재는 Career 섹션이 끝나면 페이지가 그냥 끊긴다.
- 햄버거: `md` 미만에서 아이콘 → 풀스크린 오버레이. 링크 1.8rem 이상, 터치 타겟 44px 이상,
  ESC·오버레이 클릭으로 닫기, 포커스 트랩. 이게 들어가면 320px에서 내비가 잘리는 문제도
  같이 해결된다.

## 구현 순서

각 단계는 독립적으로 검증 가능하고, 어느 단계에서든 멈출 수 있다.

- **A** 색 토큰 + 다크모드 토글 — 전 컴포넌트를 건드린다. 나머지가 전부 여기 의존한다.
- **B** 햄버거 + 스크롤 진행바 내비
- **C** 푸터 + 맨 위로 버튼
- **D** 히어로 재작업(시그니처 + 애니메이션 배경)
- **E** 섹션 리빌 강화 + 카드 tilt

## 검증

단계마다 확인한다.

- `npx next build` 통과(lint + 타입체크 포함)
- 320 / 360 / 375 / 744 / 1200px에서 가로 스크롤 없음
- 라이트/다크 양쪽에서 전 섹션 대비 확인
- `prefers-reduced-motion: reduce`에서 모션이 실제로 죽는지 확인
- 키보드만으로 내비·햄버거·모달 조작 가능
